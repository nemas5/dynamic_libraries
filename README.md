# Автоматическое подключение динамических библиотек

Основная программа,
реализованная в main.cpp производит в директории plugins поиск подключаемых
плагинов (формата .so), и все найденные автоматически регистрирует.

При инициализации экземпляра класса Plugins конструктор выполняет
поиск в директории plugins файлов формата .so и динамически линкует их с
помощью dlsym. В экземпляре класса Plugins находятся два словаря для хранения
функций-решателей и функций вывода решения.

Данный метод расширения функциональных возможностей программных
систем позволяет автоматически подключать плагины к исполняемой программе
путём их добавления в предусмотренную для этого директорию
